Methodology & sources

Each axis is scored left% = (Σ ± answer + 2n) / 4n × 100 over balanced-pro-polarity Likert items (+2…−2). Two wordings are offered — concise (default) and full: same 144 items in the same order with the same axes and polarities, only the phrasing differs. Philosopher match is nearest neighbour by Euclidean distance over all axes, converted to a similarity %. Vectors are approximate portraits — disputable, for fun. Full documentation (axes, all questions, every philosopher profile, archetypes, method) lives in PHILOSOPHY.md in the repo.
